The best plan my heuristics found is passed to CP-SAT both as an
objective cut-off and as a hint, so the solver starts feasible and
only has to prove optimality.

gap = (heuristic - best feasible plan) / best feasible plan. Where
optimality is not proved the best feasible plan is an upper bound on
the optimum, so that gap is a LOWER bound on the true gap. The
certified gap uses the dual bound instead (shifted by the 1/SC
discretisation), so it is an UPPER bound on the true gap. In practice
the dual bound stays far below the primal (e.g. 27.6 against an
incumbent of 217 at n=10 in 300s), so the column documents how weak
the relaxation still is rather than certifying a useful gap.
cp_sat_improved_pct = how much the CP-SAT plan beats the best plan my
heuristics found (0.00 means the heuristic plan was not improved on).
