# W8 扩展：标准实例 + 更多无人机 + 无人机调度优化

## 1. 动机（一次处理三条局限）

W8 多无人机一节留下了三条局限：① 算例是随机几何合成；② K 只测到 3 架；③ 会合/调度用"最早可用即起飞"的简单规则，未做最优调度。这一节把三条一起处理。

## 2. 标准算例（替代随机几何）

- 用仓库里**官方 Solomon 实例**的坐标（`src/instances/official_solomon/*.vrp`），取每个实例的前 n 个顾客——与 FSTSP 文献"Solomon 实例 + 无人机"的做法一致。
- 这些文件里同族坐标相同，实际有**四种不同空间拓扑**：C101（聚类）、C201（聚类二型）、R101（均匀随机）、RC101（混合）。
- 为保持和之前合成实验可比的"续航尺度"，把坐标平移（depot 归零）并统一缩放，使顾客的 **RMS 半径等于合成生成器在同 n 下的 RMS 半径**；模型常数（车/无人机速度、服务时间、续航 R_D=160）不变。也就是**只换了空间拓扑，其余不变**。
- 规模 n = 10 / 20 / 30 / 50，共 4 × 4 = 16 个标准实例（无随机种子，确定性）。

## 3. 结果：无人机数量（K=1/2/3/5）

相对 truck-only 的 makespan 降幅（LNS 解）：

| 规模 | truck-only | K=1 | K=2 | K=3 | K=5 |
|---|---:|---:|---:|---:|---:|
| N=10 | 351.7 | 37.2% | 51.2% | 61.1% | **71.4%** |
| N=20 | 718.9 | 36.0% | 46.0% | 52.6% | **62.4%** |
| N=30 | 1218.0 | 33.5% | 43.9% | 51.5% | **57.5%** |
| N=50 | 2370.2 | 27.5% | 38.4% | 42.7% | **46.8%** |

在**标准拓扑**上结论和合成算例一致：无人机越多收益越高（K=5 时 46.8%~71.4%），并且进一步压平规模衰减曲线。逐族看，均匀随机的 R101 收益最高、聚类的 C101 较低，符合直觉（分散的顾客更适合无人机）。

## 4. 无人机调度：naive 规则到底差多少

把"架次→无人机"的分配当成显式调度问题，用同一个仿真比较三种方法：

- **greedy**：每个架次给最早可用的无人机（原来的规则）；
- **local**：从 greedy 出发，反复把单个架次换到别的无人机以降低 makespan；
- **optimal**：分支定界求精确最优（架次数 ≤ 14；加入对称性破缺后上限从 12 提到 14）。
- **下界（证书）**：取两项中较大的合法下界——(a) 每个架次独占一架无人机（无竞争）；(b) 所有架次飞行时间总和除以 K（K 架无人机的最小负载下界）。greedy 触到该下界即证明最优。

结果（标准实例，64 个 (族, n, K) 配置）：

- **local 相对 greedy 增益 0.000%**——局部搜索找不到任何改进。
- **最优性证书**：**64/64 个配置上 greedy == 下界，即 naive 规则可证明最优**。
- 精确最优对照（32 个架次数 ≤ 14 的配置）：naive 规则与**精确最优**完全一致（0.000%）。

结论：主评估器物理化后，单架/多架 LNS 产出的架次集合互不重叠，K 架无人机之间**没有竞争**，于是 naive 的"最早可用即起飞"在**全部 64 个配置上可证明最优**。（自检：greedy 与既有 `fstsp_makespan_multi` 数值完全一致，且 greedy ≥ local ≥ optimal 恒成立。）注意：这一"调度不成问题"的结论是物理化之后的性质；旧口径下 31/64 可证、其余靠下界，是嵌套架次制造的假竞争。

## 5. 局限

- 时间窗/电量：已由 V3 单独处理（电动卡车 + 无人机 + 充电 + 时间窗），见 `docs/weekly/v3_ev_collab_note_zh.md`；本节仍是 FSTSP 评估器（无 TW/电量）。
- 论文原始算例：已单独补上（Murray & Chu 2015 原始 FSTSP 算例，36 个实例），见 `docs/weekly/week08_mc_benchmark_note_zh.md`；本节的标准实例仍是 Solomon 坐标 + 统一缩放（为保持续航尺度）。
- 调度：物理化后全部 64/64 配置可证明最优（见 §4）；但这依赖架次互不重叠——若允许架次重叠，竞争会重现。
