# 论文原始算例：Murray & Chu (2015) FSTSP benchmark

## 1. 动机

之前的标准算例用的是 **Solomon 坐标 + 统一缩放**（为保持续航尺度），不是论文原始算例文件。这一节换成 Murray & Chu (2015) 的**原始 FSTSP 算例**。

## 2. 数据来源

- 数据集：`Murray_Chu_2015_test_data`（Dell'Amico、Montemanni & Novellani 随其 FSTSP 精确模型论文公开托管）。
- 已下载到 `src/instances/murray_chu_2015/`，共 **36 个 10 顾客实例**（其中 11 个附文献给出的目标值 OFV）。
- 每个实例含 `nodes.csv`（坐标 + 是否过重）、`tau.csv`、`tauprime.csv` 两张时间矩阵、`Cprime.csv`（无人机可服务的顾客）、部分含 `FSTSP_OFV.csv`（文献目标值）。节点 0 = 起点仓库、1..c = 顾客、c+1 = 终点仓库。

## 3. 哪张矩阵是卡车？用数据判定

随包的 README **没有**说明 `tau` 与 `tauprime` 分别对应哪辆车。我用数据标定：

- `nodes.csv` 第 0 行第 4 列是 README 声明的 **UAV 速度**（各实例为 0.2 / 0.4 / 0.6 miles/min）。
- 两张矩阵都近似正比于欧氏距离，可反推速度。**36/36 实例**上 `tauprime` 反推的速度与声明的 UAV 速度吻合（0.25/0.417/0.58 对应 0.2/0.4/0.6），而 `tau` 恒定在 0.33 左右、随实例不变。

⇒ **`tau` = 卡车时间矩阵，`tauprime` = 无人机时间矩阵**。

顺带发现：这套算例的 UAV 速度跨实例变化，因此**覆盖了"无人机比卡车慢（0.2）→ 相当 → 比卡车快（0.6）"三种区间**，正好可以观察协同收益随无人机速度的变化。

## 4. 结果（36 个实例，LNS，200 次迭代）

| 配置 | LNS | 相对 truck-only TSP | LNS / 文献 OFV |
|---|---:|---:|---:|
| c1K1（**严格 M&C 的 FSTSP**：每架次 1 顾客、单无人机） | 51.31 | 21.7% | **0.901** |
| c1K2 | 44.88 | 31.6% | 0.794 |
| c1K3 | 41.56 | 36.6% | 0.709 |
| c2K1（我的多顾客扩展，每架次最多 2 顾客） | 49.89 | 24.1% | 0.895 |
| c2K2 | 43.06 | 34.5% | 0.743 |
| c2K3 | 40.74 | 37.9% | 0.684 |

（"LNS / 文献 OFV"只在 11 个附 OFV 的实例上平均；< 1 表示优于文献目标值。）

- **按 M&C 自己的 FSTSP 定义（每架次 1 顾客、单无人机），我的 LNS 达到文献目标值的 0.901**，即比随算例公布的 objective 好约 9.9%。
- 多无人机继续加码：单架 21.7% → 三架 36.6%（相对 truck-only TSP）。

## 5. 必须说明的两点

- **算例文件里没有无人机续航参数**，所以我按**无限续航**运行，并如实报告解中最长飞行时间：各配置均值 25~30、最大约 62。若文献用了某个 endurance 值，部分长航段解可能不满足。
- **文献 OFV 来自 M&C 的启发式**（他们的 MILP 在 30 分钟内解不出这些 10 顾客实例），所以"优于 OFV"是相对该启发式值，不是相对已证明的最优解。
